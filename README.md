# MainStreetAI
Plain-English directory of AI tools for local service businesses.
- Data: `data/tools.json` (41 listings) · Config (base URL, Stripe links, featured partners): `config.js`
- Build: `node build.js` → `dist/` · Preview: `node serve.js 8080`
- Newsletter: `api/subscribe.js` (Vercel function; set RESEND_API_KEY, RESEND_AUDIENCE_ID)
- Deploy: Vercel reads `vercel.json` (build `node build.js`, output `dist`).

## Search & AI discovery

After each deploy run `npm run indexnow` to submit all sitemap URLs to IndexNow (Bing/ChatGPT search). The key lives in `.indexnow-key` and is served at `/<key>.txt`. robots.txt explicitly allows AI crawlers; `llms.txt` and `llms-full.txt` are generated by build.js.
